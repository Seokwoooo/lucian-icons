스킬은 프로젝트를 확인하고, 가벼운 카탈로그에서 검색한 뒤 선택한 코드만 읽습니다. 기존 버튼 기능과 라벨을 보존하고 실제 앱 상태에 연결합니다.

2. 필요한 아이콘만 가져오기

설치한 스킬 폴더에서 검색하고 코드를 확인할 수 있습니다. 아래 <skill-dir>를 실제 설치 경로로 바꾸세요.

node <skill-dir>/scripts/lucian-icons.mjs search 다운로드
node <skill-dir>/scripts/lucian-icons.mjs get download
node <skill-dir>/scripts/lucian-icons.mjs get download --out ./vendor/lucian-icons

--out은 선택한 모듈, 공유 runtime.js와 LICENSE만 복사합니다. 기존 파일을 덮어쓰지 않습니다. 패키지 안의 카탈로그와 코드를 사용하므로 오프라인에서도 동작합니다. 공개 카탈로그는 api/v1/catalog.json에서 볼 수 있습니다.

3. 기존 버튼에 연결하기

아이콘은 장식용으로 시작합니다. 기존 텍스트나 접근 가능한 이름을 남겨 두세요. 아이콘 자체가 의미를 전달한다면 label을 지정하세요.

<script type="module" src="./vendor/lucian-icons/download.js"></script>
<button type="button" id="export-report">
  <lucian-download size="24" state="idle"></lucian-download>
  <span>보고서 내보내기</span>
</button>

기존 작업 핸들러에서 실제 요청 상태를 연결하세요. 클릭은 성공이 아닙니다. 진행률을 알 수 없다면 숫자를 만들어내지 마세요.

icon.setState('progress'); // 실제 요청이 시작될 때
icon.setProgress(42);     // 서버나 작업의 실제 진행률
icon.setState('success'); // 실제 요청이 성공했을 때
icon.setState('error');   // 실제 요청이 실패했을 때

Promise 연동 예제 열기. 요청 완료와 실패를 직접 제어해 대기 상태를 검증하는 예제이며 자동 성공 타이머가 없습니다.

4. 크기, 색과 상태

size: 16~256px. accent, ink, paper: 6자리 HEX 색상. state: 해당 아이콘의 지원 상태. progress: 다운로드의 0~100 진행률. 진행률 100은 성공 상태와 별개입니다.

React에서는 클라이언트에서 모듈을 불러오고 ref 또는 속성으로 상태를 연결하세요. Vue에서는 선택한 lucian-* 태그를 custom element로 설정할 수 있습니다. 기존 프레임워크의 이벤트와 정리 과정을 유지하세요. 컴포넌트는 문서 전역 이벤트나 타이머를 등록하지 않습니다.

5. 다운로드 형식

SVG: 선택 상태의 정적 이미지. 클릭 애니메이션이 포함되지 않습니다.
HTML 및 코드 복사: 선택한 아이콘과 스타일, 동작이 모두 포함된 독립 시연. 파일을 직접 열어도 동작합니다.
적용 프롬프트: 선택한 코드와 실제 앱에 연결할 지침. 전체 카탈로그를 포함하지 않습니다.

시연 컨트롤은 앱 코드에 복사하지 마세요. 실제 요청, 취소, 오류, 접근성을 보존해야 합니다. 같은 아이콘 여러 개를 사용할 수 있으며 서로 SVG ID나 CSS가 충돌하지 않습니다.

1. Install the agent skill

Download the skill ZIP, unzip it and put the lucian-icons folder in one of these locations. SKILL.md must be directly inside that folder. The CLI needs Node.js 18+, with no packages to install.

Codex

You can also select the skill with /skills in Codex. Restart the agent if it does not discover the new skill. The skill reads your project, searches a lightweight catalog, loads only selected code, and preserves existing behavior and accessibility.

2. Retrieve only what you need

Replace <skill-dir> with the installed skill path.

node <skill-dir>/scripts/lucian-icons.mjs search download
node <skill-dir>/scripts/lucian-icons.mjs get download
node <skill-dir>/scripts/lucian-icons.mjs get download --out ./vendor/lucian-icons

--out copies the selected modules, shared runtime.js and LICENSE. It refuses existing files. The bundled versioned catalog and code work offline. The public catalog is api/v1/catalog.json.

3. Keep your button. Add the icon.

<script type="module" src="./vendor/lucian-icons/download.js"></script>
<button type="button" id="export-report">
  <lucian-download size="24" state="idle"></lucian-download>
  <span>Export report</span>
</button>

Icons are decorative by default. Keep visible text and accessible names. Supply a localized label if the icon itself conveys meaning. Connect visual state inside your existing operation handler:

icon.setState('progress'); // when the real request starts
icon.setProgress(42);     // measured progress from the operation
icon.setState('success'); // only on actual success
icon.setState('error');   // on actual failure

A click is not success. If progress is unknown, keep zero and provide the app's own indeterminate status. Open the Promise integration fixture to explicitly resolve, reject or cancel the pending request. It has no automatic success timer.

4. Size, color and state

size: 16 to 256px. accent, ink, paper: six-digit HEX colors. state: a supported catalog state. progress: 0 to 100, for download only. Progress 100 does not mean success.

In React, import on the client and synchronize attributes or a ref with your state. In Vue, configure the selected lucian-* tag as a custom element. Preserve your framework's events and cleanup. Components add no document listeners or timers.

5. Export formats

SVG: a static snapshot of the selected state, without click behavior.
HTML / Copy code: a self-contained interactive demonstration with the selected settings. Works by opening the file directly.
AI prompt: only the chosen icon's code and integration instructions.

Leave demo controls out of production. Preserve real requests, cancellation, errors and accessibility. Multiple instances coexist without SVG IDs or CSS collisions. Reduced motion preserves state changes.
