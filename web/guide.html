01설치Install

빠르게 써 보려면 전체 묶음을 불러오세요. {{ICON_COUNT}}개가 모두 <lucian-이름> 요소로 등록됩니다.

To try things quickly, load the full bundle. All {{ICON_COUNT}} icons register as <lucian-name> elements.

<script type="module" src="https://lucianlabs.dev/icons/all.js"></script>

필요한 아이콘만 쓰려면 개별 모듈을 불러옵니다. 모듈은 같은 폴더의 runtime.js를 함께 가져옵니다.

To ship only what you use, load individual modules. Each one imports the shared runtime.js next to it.

<script type="module" src="https://lucianlabs.dev/icons/modules/heart.js"></script>
<script type="module" src="https://lucianlabs.dev/icons/modules/download.js"></script>

공개 주소는 항상 최신 버전을 가리킵니다. 실제 서비스에서는 modules/아이콘.js와 modules/runtime.js를 프로젝트에 복사해 버전을 고정하세요. 소스 ZIP이나 에이전트 스킬의 get --out 명령으로 받을 수 있어요.

Public URLs always point at the latest release. In production, copy modules/icon.js and modules/runtime.js into your project to pin the version. Get them from the source ZIP or the agent skill’s get --out command.

02기본 사용Basics

기존 버튼이나 링크 안에 넣으세요. 아이콘은 가장 가까운 button, a, [role=button] 같은 컨트롤에 마우스를 올리거나 키보드로 포커스하면 효과를 재생합니다. 터치에서는 누를 때 재생해요.

Put the icon inside your existing button or link. It plays its effect when the nearest control (button, a, [role=button] and similar) is hovered or receives keyboard focus, and on press for touch.

<button type="button" class="like" aria-pressed="false">
  <lucian-heart></lucian-heart>
  <span>좋아요</span>
</button>
링크Link

아이콘은 기본적으로 장식으로 취급되어 보조 기술에서 숨겨집니다. 버튼의 글자나 aria-label을 그대로 두세요. 글자 없이 아이콘만으로 뜻을 전한다면 label 속성에 현지화된 설명을 넣습니다.

Icons are decorative by default and hidden from assistive technology. Keep your button’s text or aria-label. When the icon alone carries meaning, give it a localized label.

The element registers no document listeners or timers. Listeners on the nearest control are removed when the element leaves the document.

05상태는 앱이 정합니다Your app owns the state

상태가 있는 아이콘 {{STATEFUL_COUNT}}개는 앱의 실제 상태를 보여 주는 표시등입니다. 클릭은 성공이 아니에요. 요청이 끝났을 때, 값이 실제로 바뀌었을 때 setState()를 부르세요.

The {{STATEFUL_COUNT}} stateful icons are indicators of real application state. A click is not success. Call setState() when the request settles or the value actually changes.

const button = document.querySelector('#export');
const icon = button.querySelector('lucian-download');

button.addEventListener('click', async () => {
  icon.setState('progress');
  try {
    await exportReport({ onProgress: percent => icon.setProgress(percent) });
    icon.setState('success');
  } catch (error) {
    icon.setState(error.name === 'AbortError' ? 'idle' : 'error');
  }
});

시연용 컨트롤Demo controls · idle

진행률을 모르면 숫자를 지어내지 말고 progress 상태만 두세요. 진행률 100은 성공과 다릅니다. 버튼의 disabled, aria-busy, aria-pressed, 상태 문구는 요소가 건드리지 않으니 앱에서 관리합니다.

If you don’t know the progress, don’t invent a number; stay in progress. Progress 100 is not success. The element never touches your button’s disabled, aria-busy, aria-pressed or status text; your app manages them.

Promise 연동 예제는 자동 성공 타이머 없이 대기, 성공, 실패, 취소를 직접 눌러 확인합니다.

The Promise integration example lets you resolve, reject and cancel by hand, with no timer faking success.

06색과 톤Color and tone

선은 언제나 글자색(currentColor)을 따르고, 면과 포인트는 아이콘마다 고른 고유 색을 씁니다. 페이지가 color-scheme: dark를 선언한 다크 테마에서는 면이 어두운 배경에 묻혀 탁해지지 않도록 아이콘 색을 조금 더 깊고 진하게 칠하고, 포인트는 조금 밝게 바꿔요. 하트나 별처럼 상태에 따라 채워지는 아이콘은 꺼짐일 때 테두리만 남아요. 다크 테마라면 대개 이미 선언되어 있어요.

Strokes always follow the text color (currentColor); surfaces and details use each icon’s own hue. When the page declares color-scheme: dark, surfaces are painted in a slightly deeper, richer version of the icon’s color so they do not turn muddy on a dark background, and details get a little lighter. Icons that fill with their state, such as heart and star, are just an outline when off. Most dark themes already declare it.

/* 브랜드 색 하나로 맞추기 · One brand hue */
.toolbar { --li-accent: var(--brand); }

/* 면 채움 진하기 0–1 (기본 .24) · Surface tint 0–1 (default .24) */
.dense { --li-tint: 0; }

/* 크기와 굵기 · Size and weight */
.nav lucian-home { --li-size: 20px; --li-weight: 2; color: var(--text-2); }

07모션과 접근성Motion and accessibility

  • 스프링 전환. 상태가 바뀌면 부품마다 스프링 곡선으로 움직입니다. 전환 중에 다시 바뀌어도 지금 그려진 자리에서 이어서 갑니다.
  • 겹쳐지는 효과. 마우스 효과는 상태 위에 더해지는 방식이라 열린 상태의 쓰레기통도 자연스럽게 흔들립니다.
  • 상태 루프. 전화의 ringing, 새로고침의 loading처럼 계속 움직여야 하는 상태는 그 상태일 때만 반복하고, 벗어나면 한 바퀴를 마저 돈 뒤 멈춥니다.
  • 동작 줄이기. prefers-reduced-motion이 켜져 있으면 움직임 없이 최종 모양과 진행률만 바로 보여 줍니다.
  • 격리. 아이콘마다 자기 Shadow DOM을 써서 SVG ID나 CSS가 서로 부딪치지 않습니다. 같은 아이콘을 여러 개 써도 괜찮아요.
  • Spring transitions. Each part springs to its new pose. If the state changes mid-flight, motion continues from where it is drawn.
  • Additive effects. Hover effects add on top of the state, so an open trash can still wiggles naturally.
  • State loops. States that keep moving, like the phone’s ringing or refresh’s loading, loop only while active and finish their cycle on exit.
  • Reduced motion. With prefers-reduced-motion, icons jump straight to the final pose and progress.
  • Isolation. Every icon has its own shadow root, so SVG IDs and CSS never collide. Repeat icons freely.

08프레임워크Frameworks

React

클라이언트에서 모듈을 불러오고 속성으로 상태를 넘기세요. React 19는 커스텀 요소의 속성을 그대로 전달합니다.

Import the module on the client and pass state as an attribute. React 19 forwards custom element attributes as is.

import './vendor/lucian-icons/heart.js';

export function LikeButton({ liked, onToggle }) {
  return (
    <button type="button" aria-pressed={liked} onClick={onToggle}>
      <lucian-heart state={liked ? 'on' : 'off'} />
      <span>Like</span>
    </button>
  );
}

Next.js 같은 SSR 환경에서는 'use client' 컴포넌트나 useEffect 안에서만 불러오세요. TypeScript에서는 JSX.IntrinsicElements에 'lucian-heart'를 선언합니다.

In SSR frameworks like Next.js, import only in a 'use client' component or inside useEffect. In TypeScript, declare 'lucian-heart' in JSX.IntrinsicElements.

Vue · Svelte

// vite.config.js

10에이전트 스킬Agent skill

스킬을 설치하면 Claude Code와 Codex가 카탈로그에서 알맞은 아이콘을 찾아 기존 버튼과 상태에 연결합니다. 오프라인으로 동작하고, 고른 아이콘의 코드만 읽어요.

With the skill installed, Claude Code and Codex search the catalog, pick the right icon and wire it to your existing buttons and state. It works offline and reads only the code it picks.

121.x에서 옮기기Moving from 1.x

  • 색. ink, paper 속성은 없어졌습니다. 선은 color(글자색)를, 포인트는 accent나 --li-accent를 쓰세요.
  • 상태. 상태는 실제 앱 상태를 나타낼 때만 남겼습니다. 예를 들어 벨은 ringing 대신 unread가 되었고, 마우스 반응만 있던 아이콘 69개는 상태 없이 효과로 바뀌었어요. 상태 이름은 위 목록을 확인하세요.
  • 효과. 마우스와 포커스 반응이 자동으로 붙습니다. 직접 제어하려면 animate="none"과 play()를 쓰세요.
  • 이전 버전. 1.x 패키지는 스킬 1.2.0, 소스 1.2.0으로 계속 받을 수 있습니다.
  • Color. The ink and paper attributes are gone. Strokes use color (the text color); details use accent or --li-accent.
  • States. States remain only where they mirror real app state. The bell’s ringing became unread, for example, and 69 hover-only icons now play an effect without states. Check the list above for names.
  • Effects. Hover and focus responses attach automatically. For manual control use animate="none" and play().
  • Older versions. 1.x packages remain available: skill 1.2.0 and source 1.2.0.
