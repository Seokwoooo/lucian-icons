# Lucian Icons 2.0 design brief

Goal: icons people want to press. 2.0 replaces the 1.x drawings, runtime and gallery. It keeps all 112 IDs and adds 100 new icons (212 total, 13 categories). Release 2.0.4 removed `eye`, leaving 211.

Drawing: 24-unit grid, 1.75 default stroke, round caps and joins, `currentColor` ink strokes. Each icon gets one hue from a 15-step palette (red, coral, orange, amber, yellow, lime, green, teal, cyan, blue, indigo, violet, purple, pink, slate) chosen for its subject. The hue paints a tinted surface (`.s`, `--li-tint` .24), accent strokes (`.a`) and small solid details (`.f`). Error marks (`.e`: the download and upload error, the shield alert) are a fixed red, `#F05465`, so a failure never takes a calm color such as green; they ignore `accent`, follow the line color in line tone and lighten in dark themes like accents (since 2.0.9). The shield's surface fades out on alert, so its red mark never sits on a green fill. On pages that declare `color-scheme: dark`, a thin tint over the dark page turned yellow olive and orange brown, so since 2.0.8 surfaces are painted solid in a slightly deeper, richer version of the hue (OKLCH lightness x.93, chroma x1.08; x.8 looked too dark, the pure color too bright and x.9 with less chroma faded) and accents move 40% of the way to white. The eight icons whose state fills the whole shape (a `.f` part named `fill` or `glow`: heart, star, bookmark, thumbs up, toggle, filter, bulb, lamp) are just an outline when off and fill with their own color when on. It uses `light-dark()` and relative colors behind `@supports`; older browsers keep the light rendering. Static SVG exports are unchanged. The gallery draws strokes at 1.35 in its dark theme, because white lines on a dark page look heavier; the component default stays 1.75. `tone="line"` folds everything into `currentColor` for monochrome interfaces; adding `accent` colors only the details (two-tone line), in the component and in static SVG exports alike. Every icon reads at 16px; details that do not survive 16px are removed.

Motion: parts are named with `data-part`. A state is a pose per part (rotate, translate, scale, skewX, opacity, draw). Transitions between states use spring curves (snappy, bouncy, smooth, gentle) generated as CSS `linear()` easing, with optional keyframed paths for overshoot and anticipation. Interrupted transitions continue from the rendered values. Hover effects are additive keyframes (`composite: 'add'`), so they work on top of any state. Looping states (ringing, loading, syncing, playing) run only while active and finish their cycle on exit. Reduced motion jumps to the final pose.

States: only where they mirror real application state (on/off, unread, locked, progress, copied). Visual-only 1.x states such as pressed or raised became hover effects. 53 icons had states at 2.0.0; 52 after `eye` was removed in 2.0.4.

Gallery (redesigned in 2.0.5): the page no longer borrows the uxui-prompt look (warm paper, glow tiles, gradient title, sliding pills). It is a quiet specimen sheet: an off-white page (`#FAFAF9`, `#09090A` in dark), one hairline table per category with five icons per row on desktop (four on tablets, three on phones), a floating glass toolbar, a 640-weight headline, and Geist Mono for numbers and code beside Pretendard. Its own motif is the 24-unit drawing grid with circle and square keylines, shown behind the large icon in the hero card, the inspector and the reels. The autoplay is unchanged from uxui-prompt on purpose: every icon at least half in view is demonstrated by a Mac-style cursor that glides in, triggers the effect, clicks through every state, leaves and repeats; hover changes nothing and keyboard focus takes over. The hero card cycles six featured icons (heart, bell, bulb, download, Wi-Fi, bookmark) with the same cursor. On screens 1180px and wider a click steps the icon and slides in an inspector beside the deck (the deck keeps five per row); on narrower screens a click opens the reel, where the icon grows out of its cell onto the grid. The inspector moves into a sheet over the reel and on small screens. Since 2.0.10 it opens on the Prompt tab (the reel's Copy also copies the prompt), and right below the copy button a skill card recommends the agent skill with two requests to copy: let the AI pick fitting icons, or ask for this icon by its gallery number. Above the headline, "100% 무료 오픈소스" / "100% free & open source" sits on its own line in a deep orange from the bell icon (`#E0590B`, `#FF9A45` in dark) with a hand-drawn underline that draws in once. The API guide shares the header, buttons and code blocks. The share image `og.png` (1200x630) repeats the hero headline and counts beside a six-cell excerpt of the specimen table, with the heart on the keyline grid; it has no version number, so redraw it only when the icon, category or state counts change. Its URL carries `?v=<version>` so link previews pick up a new image on each release.

Distribution: `all.js`, per-icon ES modules with a shared runtime, JSON API, static SVG and standalone HTML downloads, source and skill ZIPs, and the lucian-icons agent skill. Public module paths send `Access-Control-Allow-Origin: *` so the one-line script works from any site.
