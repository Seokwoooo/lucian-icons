identify the project and its owner. They are not part of the MIT-licensed icon
collection. No trademark rights are granted by the software license.

Logo source files and branded artwork are not bundled in this repository or its
packages. The official gallery and API guide reference the owner's existing
`https://lucianlabs.dev/favicon.svg` for their header logo and browser favicon;
that separately hosted asset is not part of the icon library. The footer uses
the library name as text, and the branded social preview has been removed.

The remaining Lucian Icons name identifies this library; it does not grant
permission to use the owner's brand as your own or imply affiliation or
endorsement. Obtain the owner's permission for uses that require it; rights
available under applicable law are unaffected.

Website source ZIP downloads have been withdrawn because they bundled the
branded website with the icon library. Individual icon exports and the agent
skill contain the library, not the Loop L logo.
